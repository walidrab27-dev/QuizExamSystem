# Quiz Exam System 🎓

A comprehensive backend management system for generating and grading exams, built to demonstrate robust server-side logic and clean code practices.

> **Note:** This project is currently under active development (Work in Progress).

## 🚀 Project Overview
The Quiz Exam System is designed to handle core educational business logic, including student authentication, exam generation, and automated grading. It separates data processing from user interface display, adhering to clean architecture and strict Object-Oriented Programming (OOP) principles.

## 🛠️ Technologies Used
* **Language:** C#
* **Core Concepts:** Object-Oriented Programming (OOP), LINQ
* **Database:** SQL (Relational Database Design)
* **Architecture:** Modular classes and service layers

## ✨ Key Features (Implemented & Planned)
* Architected scalable models and service classes for subjects, exams, and student records.
* Integrated relational database logic to securely store and retrieve historical exam results.
* Utilized LINQ queries to process and filter student performance metrics.
* Engineered a structured Student Dashboard to ensure a maintainable and modular codebase.
